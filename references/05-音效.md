# 05 音效

什么时候读：画面定稿以后、配乐之前。产出是时间轴里的 `sfx`，再用 `python3 scripts/bgm.py sfx timeline.json` 出「纯音效」和「人声+音效」两条轨。

## 1. 原则：声音是画面的影子

- 看得见的东西出现时才有声音，声音的轻重和视觉重量成正比。
- 普通剪切不配音效。一条 106 个镜头的爆款对标实测：剪切点前后 0.25 秒内出现明显起音的比例是 28%，随机时间点是 29%，几乎一样。也就是说，它并不在剪切点上放音效。
- 密度跟着 01 的密度曲线走：开头密，后面逐渐收。

| 段落（占片长） | 音效间隔 | 配给谁 |
|---|---|---|
| 钩子 0–9% | 0.3–0.5 秒一个 | 贴脸字段只给大字配声，小字不配 |
| 框架 9–24% | 1–2 秒一个 | 关键词、版式切换 |
| 主体 24–83% | 4–8 秒一个 | 界面动作、章节标题、改前改后 |
| 结尾 83–100% | 全段 3–4 个 | 情绪顶点 |

## 2. 画面事件 → 声音

dB 是 `sfx.items[].db` 的起点值，按耳朵再微调；人声按原片电平。

| 画面事件 | 声音类型 | 起点 dB | 对齐 |
|---|---|---|---|
| 强调色大字、重字砸下 | 低频重击（thump） | -8 到 -10 | 峰值对准落位那一帧 |
| 白色大字 | 拳击类中击 | -12 | 峰值 |
| 玻璃胶囊、标签弹出 | pop / tick，几种轮换 | -16 到 -20 | 峰值 |
| 文件发给 AI、指令发出 | 「已发送」类短提示音 | -14 | 峰值 |
| 镜头急推落位 | 很轻的风声（air） | -17 到 -19 | 峰值对准落位 |
| 章节失焦转场 | 柔和 whoosh | -14 | 从失焦开始播（`"align": "start"`） |
| 改前改后划屏 | swipe | -14 | 峰值对准擦过中线 |
| 数字滚动 | tick 连击 3–4 下，音调逐级升高 | -18 | 每下对准一次数字变化 |
| 进度走完、完成 | 清脆的单音（glass / ping） | -14 | 峰值 |

## 3. 写进时间轴

```json
"sfx": {
  "pools": {"pop": ["sfx/pop1.wav", "sfx/pop2.wav", "sfx/card.wav"], "thump": ["sfx/thump1.wav", "sfx/thump2.wav"]},
  "items": [
    {"t": 3.97, "pool": "thump", "db": -8},
    {"t": 10.62, "pool": "pop", "db": -18},
    {"t": 15.53, "file": "sfx/whoosh_soft.wav", "db": -14, "align": "start"}
  ]
}
```

- `t` 直接抄画面事件的时间：贴脸字取 `words[].t`；`big.settle` 是 0.09 秒，所以落位帧是 t + 0.09；玻璃取 `items[].t`。
- 默认 `"align": "peak"`：音效最响的那一下落在 `t`，不用手算音效文件开头的空白。
- 同类声音放进同一个 `pool`，脚本会轮换着用，相邻两次不重样，避免听出循环感。

## 4. 音效从哪来

skill 不附带音效文件。可以从这两个地方找：

- **CC0 音效**：Openverse、Freesound 上筛选 CC0 授权，可商用、不用署名。每个文件的来源链接记进项目的 `sfx/SOURCES.md`。
- **macOS 系统音效**：在 `/System/Library/Sounds/` 和 `/System/Library/Components/CoreAudio.component/Contents/SharedSupport/SystemSounds/`。版权归 Apple，没有公开的使用许可，只能在自己机器上用；不要打包进 skill，也不要分发给别人。介意的话全部换成 CC0。

## 5. 检查

| 检查 | 通过标准 |
|---|---|
| 对点 | 抽 3 个音效，在波形上看峰值，离目标帧不超过 1 帧（33 毫秒） |
| 贴脸字段 | 只有大字有声，小字没有 |
| 普通剪切 | 没有为剪切本身配的音效 |
| 重样 | 同一个文件没有连续出现 |
| 和配乐的关系 | 音效密集的地方，配乐保持平，不加 fill（见 06） |
| 音量 | 戴耳机听，没有一个音效比人声还抢耳朵 |

## 6. 不要

- 不要每个字、每一刀都配声。最常见的反馈是「太吵」。
- 不要用一整套风格很重的商用音效包从头铺到尾。
- 不要用 ffmpeg 一次开几百个输入去混音效，用 `bgm.py sfx`。
- 不要对口播做降噪、压缩或响度处理来「配合」音效。口播保持原片电平，限幅只防叠加时爆音。
