# 02 对标拆解协议

什么时候读：用户给了一条「我想要这个感觉」的对标视频。动手渲染之前，必须先走完这份协议。

## 0. 为什么要有这份协议

风格对不上、反复改，原因几乎都是下面四种，这份协议逐条堵上：

| 反复改的原因 | 例子 | 这份协议怎么防 |
|---|---|---|
| 用形容词描述风格 | 「干净、高级、有冲击力」，每个人脑子里的画面都不一样 | 每条观察都要写成数字，并附证据帧 |
| 加了参考里没有的东西 | 绕头转圈的字、底部大黄字、嘴边的声波圈，都是参考里没有的花样 | 报告里必须有一节「参考里没有的东西」，渲染时逐条核对 |
| 字体气质不对 | 参考用特粗窄体，结果用了又圆又胖的黑体 | 先判断字体类别（窄 / 宽、几何 / 人文、大小写），再选替代字体 |
| 凭印象判断时机和幅度 | 以为音效都卡在剪切点上，实测其实和随机位置一样；以为重点词从 110% 落位，实测第一帧就是最终大小 | 时机和幅度类的结论都要测出来，不靠看一遍的感觉 |

## 1. 先问用户三件事

1. 对标视频文件（原画质，不要录屏转录屏）。
2. **具体是哪几秒**让他觉得「就要这个」：给 2–5 个时间点。不要拆整条视频，只拆他指的地方。
3. 他**不喜欢**什么：以前做过但被他否掉的效果。直接写进报告第 5 节。

## 2. 宏观测量（整条视频，几分钟出结果）

工具是 `scripts/analyze_ref.py`，只依赖 numpy、pillow 和 ffmpeg。`all` 会一次跑完切点、音效和总览图，结果写进 `--out` 目录。

```
python3 scripts/analyze_ref.py sheet 对标.mp4 --grid            # 先看全貌：每秒 4 张，叠 0.1 网格
python3 scripts/analyze_ref.py cuts 对标.mp4                    # 切点、镜头数、中位镜头时长、每分钟切换、实际内容帧率
python3 scripts/analyze_ref.py sfx 对标.mp4                     # 音效起音和切点的关系
python3 scripts/analyze_ref.py people 对标.mp4 --model selfie_multiclass_256x256.tflite   # 人物占比（要 mediapipe）
```

| 指标 | 命令 | 用来定什么 |
|---|---|---|
| 镜头数、平均 / 中位镜头时长、最长镜头 | `cuts` | 01 的画面变化间隔 |
| 每分钟切换数 | `cuts` | 密度曲线的形状 |
| 实际内容帧率 | `cuts`。明显低于文件帧率，说明有重复帧（比如 30 帧的片装在 60 帧的录屏里） | 数入场帧数时按这个帧率算 |
| 人物占比、最长连续出镜、第一次切离人物 | `people` | 版式 A 的占比和单段上限、钩子怎么开 |
| 音效和切点的关系 | `sfx`：切点前后 0.25 秒内有起音的比例，对比随机位置 | 两个比例接近，说明不卡点 |

对标是录屏、画面套在卡片里、四周还有别的画面时，加 `--crop 左 上 右 下`（比例），只分析卡片那一块。

## 3. 微观逐帧（只拆用户指的那几秒）

分两步：先自动扫出候选，再逐个精测。

**第一步：扫候选**

```
python3 scripts/transcribe.py 对标.mp4 --lang en --out ref_words.json     # 对标音频的逐字时间轴，用来测出字时机
python3 scripts/analyze_ref.py text 对标.mp4 --range 0 9 --words ref_words.json --out 拆解/
```

自动找「上一帧没有、之后稳定存在」的字，每个候选在 `拆解/证据帧/` 里出一张证据条：出现前一帧、出现帧、之后逐帧，框出字的位置。
背景在动、人在动、字跟着镜头漂的素材会有误报和漏报，所以扫出来的只是候选。

**第二步：精测**

看证据条和带网格的总览（`sheet --grid`，或 `sheet --at 秒 --dur 0.3` 看原帧率逐帧），把确认是字的写成清单：

```json
[{"text": "EXACT", "t": 3.3, "box": [0.62, 0.33, 0.96, 0.5]},
 {"text": "and", "t": 2.8, "box": [0.12, 0.4, 0.2, 0.45]}]
```

`t` 是大致出现时间，前后 0.35 秒内都能找到；`box` 框住它刚出现时的位置。然后逐个测：

```
python3 scripts/analyze_ref.py measure 对标.mp4 --list 字.json --words ref_words.json --out 拆解/精测
```

每个字测这些：
- 出现帧，以及比开口晚几帧；
- 字高；
- 颜色。会标出半透明或和背景混色的白字；
- 每帧缩放：拿落位后的字形当模板往回逐帧匹配，即使字边入场边移动也能测；
- 首帧偏移、落位帧数；
- 虚焦、描边阴影；
- 停留期间跟着画面漂了多少；
- 什么时候清掉，是否随切镜清掉。

汇总里还会给出：大小层级比、一词一行的比例、换行错位、出字时机的中位数。

**精度和限制**

- 缩放的测量误差约 ±4%，字高不到 45 像素（按 1080 宽算）时约 ±10%。小字的入场以证据条为准。
- 字体测不了，看证据条按第 6 节判断类别。
- 「字藏在人身后」测不了，看证据条。
- 测出来的数和你的印象对不上时，用 `sheet --at 秒 --dur 0.15 --crop …` 出原分辨率逐帧图复核，以逐帧图为准。

**每一项对应的参数**

| 维度 | 工具字段 | 对应参数 |
|---|---|---|
| 出现时机 | `比开口晚帧数` | 时间轴 `words[].t` 的取法（默认：说出口那一帧） |
| 入场 | `首帧放大`、`落位帧数`、`首帧偏移_1080`、`每帧缩放` | `big.from_scale`、`big.settle`、`big.dy`；`small.fade`、`small.rise` |
| 层级 | `层级.大小比`、`字高_1080` | `words[].size`、`kind` |
| 字体 | 人工看证据条 | `fonts.big`、`fonts.small`、`fonts.zh`（见第 6 节） |
| 颜色 | `颜色`、`颜色名` | `colors.white`、`colors.accent`（按色相取，亮度按自己片子的调色校） |
| 描边阴影 | `字边暗圈`（明显小于 0.7 才算有） | `word.shadow`、`word.glow` |
| 虚焦 | `虚焦` | `word.soft` |
| 漂移 | `停留期间每秒位移_1080` | `float`、`parallax` |
| 排版 | `排版.同屏相邻两词分行的比例`、`换行时的左右错位` | `layout.tuck`、`layout.gap`、`words[].side`、`stag` |
| 留存 | `随切镜清掉`、`停留秒` | `blocks` 的边界 |
| 遮挡 | 人工看证据条 | `behind` |
| 镜头 | `sheet --at` 逐帧看 | `camera.spring`、`camera.push`、`whip.threshold` |
| 玻璃 | `sheet --at` 逐帧看 | `material.*`、`morph.*`（见 03） |

## 4. 报告模板（给用户确认用）

```
# 对标拆解：<视频名> <时间点>

## 1. 一句话结论
（例：每个词说出口就出现，出来不消失；重点词特粗窄体，116% 落位 0.09 秒；字贴脸两侧，不压脸。）

## 2. 宏观数字
| 指标 | 数值 |

## 3. 逐项观察
| 维度 | 观察（数字） | 证据帧 | 对应参数 | 把握 |
（「把握」写 高 / 中 / 低；低的才拿去问用户）

## 4. 字体替代
| 层级 | 参考里的样子 | 替代字体 | 差异 |

## 5. 参考里没有的东西（渲染时不许出现）
- 例：没有描边；没有逐字打字；没有回弹；没有底部字幕底框……
- 用户以前否掉的效果也写在这里

## 6. 我要问你的
（只问「把握：低」的项，每问附两张证据帧）
```

报告交给用户之前，先自己检查：第 3 节里有没有哪一格只写了形容词、没有数字。有就补测。

## 5. 转成参数

用户确认以后：

1. 选最接近的预设当底子：贴脸字幕用 `presets/kinetic.json`，玻璃用 `presets/glass.json`。
2. 只把**和预设不一样的值**写进一个新预设（例如 `presets/对标-xxx.json`），或者写进时间轴段落的 `style` 里覆盖。不要改原预设。
3. 出 3 张静帧，和对标的同类帧左右并排拼成一张对照图（`compose.py --stills`，再用 PIL 拼图）。对照图给用户看，他点头再出 30 秒样片。
4. 预设里没有的效果，按 `03` / `04` 末尾的「预设外的效果」流程新写。

## 6. 字体替代表（免费、可商用）

| 参考里的类别 | 先试 | 备选 |
|---|---|---|
| 特粗窄体全大写（标题、重点词） | Anton | Bebas Neue、Oswald Bold |
| 几何无衬线、中粗、小写 | Montserrat SemiBold | Poppins Medium、Inter SemiBold |
| 中文标题、有棱角的粗体 | 得意黑（Smiley Sans） | 优设标题黑（需从优设官网下载并核对授权） |
| 中文正文、字幕 | 得意黑 | 霞鹜文楷（偏手写）、系统苹方 |

选字体只看两件事：笔画粗细的对比，和字宽。圆胖的黑体（比如思源黑体 Heavy）放在窄体的位置，气质一定不对。

## 7. 不要

- 不要没拆完就开始渲染「先试一版看看」，这正是反复改的起点。
- 不要拆整条视频的每一秒：只拆用户指的地方，宏观数字够定节奏就行。
- 不要把对标里的具体文字、Logo、人物、配乐直接搬过来。拆的是手法和参数，不是内容。
- 不要让报告只剩形容词。
- 不要擅自加参考里没有的效果。想加，先在报告里单独列出来，问用户。
