# 04 贴脸字幕运镜

什么时候读：做版式 A，也就是口播全屏、字一个词一个词贴着脸出现、镜头跟着关键词急推的段落。
代码在 `scripts/kinetic.py`，手感参数在 `presets/kinetic.json`，人像遮罩在 `scripts/masks.py`。

## 1. 这套效果的六条规则

| # | 规则 | 参数 / 写法 |
|---|---|---|
| 1 | 词说出口的那一帧就亮，不提前，不逐字打字 | `words[].t` 取逐字时间轴里这个词的 t0 |
| 2 | 出来以后不消失，一块一块叠起来；镜头一切，整块一起清掉 | 一个镜头块（`blocks`）= 一屏字；下一块开始时上一块的字自动清掉 |
| 3 | 贴脸但不压脸：字在头的左、右、头顶交错出现，行与行之间斜着错开 | `side` L / R / T，`stag` 错位；离脸距离 `layout.gap` 22 像素（放进 behind 的字反过来往里收 `layout.tuck` 26） |
| 4 | 小词和重点词交替，节奏来自大小对比 | 小词 `kind: s` 约 58 像素；重点词 `kind: b`，按头旁空间撑满。近景头旁一般放得下 120–150 像素（Anton 每个字母宽约字号的 0.45 倍，3–5 个字母）；200–280 像素只在头顶（T）或人比较小的景别里放得下 |
| 5 | 镜头动必须有原因：关键词上急推，其他时间慢推不停 | `blocks[].cam`；`camera.spring` [4.6, 0.58]；`camera.push` 0.028 |
| 6 | 克制：白字加一个强调色，平面字，几乎没有阴影 | `colors`；`word.shadow` 95、`glow` 70 |

## 2. 字

| 层级 | 字体 | 入场 | 参数 |
|---|---|---|---|
| 小词（you / the / and） | Montserrat SemiBold，全小写 | 0.067 秒淡入，同时上浮 9 像素 | `small.fade`、`small.rise` |
| 重点词（VISUALS / EXACT） | Anton，全大写 | 第一帧放大 116%、位置偏上 16 像素，0.09 秒落位；没有回弹，没有拖影 | `big.from_scale`、`big.settle`、`big.dy` |
| 重字（全片最重的 2–4 个词） | Anton，强调色 | 从 135% 用弹簧落位，前 0.25 秒抖一下，同时画面震 | `fx: "hit"`；`hit.spring` [3.0, 0.5]、`hit.jitter` 7 |
| 翻牌计数（v1 v2 v3 → FINAL） | Anton | 在同一位置快速换字 | `fx: "flip"`，`items: [[t, 文字, 颜色], ...]` |
| 中文小标题（01 节奏） | 得意黑，编号 Anton 橙 | 头旁出现约 0.8 秒 | `fx: "zh"`，`num` |

- 贴脸英文是意译：短、口语化，只挑能被看见的词，不逐字翻译。
- 中文口播配英文贴脸字是这套风格的默认做法，开工前跟用户确认一句。想用中文，在段落里写 `"style": {"fonts": {"big": "SmileySans-Oblique.ttf", "small": "SmileySans-Oblique.ttf"}}`（全片都用中文就另存一个预设）。重点词控制在 2–4 个字。
- Anton 和 Montserrat 没有中文字形，中文写进去会画成方块，而且渲染不报错。`timeline.py check` 会查出来。
- 字一直在轻微浮动（`float` x 3.2、y 4.0 像素），并随镜头视差移动（`parallax` 小词 0.5、大词 0.8），这样字是「在空间里」，而不是贴在屏幕上。

## 3. 镜头

- 一个镜头块：`{"t0": 急推开始, "land": 落位时间, "cam": [取景中心 x, 取景中心 y, 放大倍数, 旋转角度]}`，坐标是原片铺满画布后的像素位置。
- 放大倍数 1.0–1.45，旋转不超过 ±2.2°。
- **给字腾地方是镜头的事**：人坐在画面正中的近景，头两侧放不下重点词，字号会被自动缩到看不见。办法是让取景中心偏离脸：
  - 字放头**左边**（L）：`cam` 的 x **调小**，脸被推到屏幕右边，左边空出来。
  - 字放头**右边**（R）：`cam` 的 x **调大**，脸被推到左边。
  - 能挪多远取决于放大倍数：放大 1.0 时一点都挪不了（会露出原片边缘），1.2 约 ±90，1.45 约 ±170。`fit_cam` 会把超出的部分悄悄限回来，所以想推到最边，直接写一个很小（L）或很大（R）的 x 就行。
  - 头两侧都不够时，用 `side: "T"` 放头顶，`stag` 写中心 x。不要把重点词挪到胸口或手上，那就不是「贴脸」了。
  - `timeline.py check` 会报出每个放不下的词的实际字号，并告诉你这一块的镜头还能往哪边挪多少。
- 急推用弹簧 `sp(t, 4.6, 0.58)`，约 0.09 秒到位。镜头速度超过 `whip.threshold` 40 时，同一帧会叠 3–12 个机位，做出动态模糊。
- 落位以后每秒慢推 2.8%，画面不停。
- 重字砸下时用 `shakes: [[t, 振幅]]` 震一下，振幅 10–18 像素，衰减系数 14；也可以用 `punches: [[t, 0.04]]` 推一档。
- 原片要高清解码：4K 原片 source 写 `"scale": 1.5`（按 1620×2880 解码），推镜时直接取高清像素，不是把 1080 的画面放大。

## 4. 字藏到人身后

- 先生成人像遮罩：`python3 scripts/masks.py 口播.mov work/masks --model selfie_multiclass_256x256.tflite --range 60 90`（需要 mediapipe 和它的人像分割模型；输出 540×960 的 PNG 就够），再在时间轴写 `"masks": {"aroll": "work/masks"}`。`--range` 用**原片时间**，读取时会按 source 的 `offset` 自动换算。30 秒大约要 2 分钟。
- 遮罩也让贴脸字知道脸的真实宽度。没有遮罩时，按 `layout.head_w` 470 像素估，近景人脸更宽时字会压脸。
- 把要藏的词写进 `behind`。最适合的是大字主词：放在头顶居中，下沿藏进头发里。只藏字高的 10–15%：藏多了，E 会变成 F，B 会变成 R，读不出来。check 会估算藏进去的比例。
- 没有遮罩时，字照常显示，只是不会被挡住，效果降级但不报错。

## 5. 排一段的步骤

1. 从逐字时间轴里挑出这一段要上屏的词：钩子段每个词都上，其他段只挑关键词（见 01 的密度曲线）。
2. 按语义切镜头块：一个意思一块，通常 2–4 秒。每块的 `t0` 放在新意思的第一个词前 0.05–0.1 秒。
3. 给每个词定 `kind`、`side`、`y`：同一块里左右交替，往下走的时候每行错开 `stag` 10–40 像素。
4. 重点词和强调色省着用：一块里最多一个强调色词。
5. 跑 `timeline.py check`：它会按渲染时同一套算法摆一遍字，报出被脸挤小的重点词、推回来会压到脸的小词、出安全区和压字幕带的字、字体里没有的字。
6. 出静帧：每块落位后 0.3 秒一张，再在急推中间出一张，看动态模糊。

## 6. 检查

| 检查 | 通过标准 |
|---|---|
| 时机 | 抽 3 个词，对照波形：出现帧和说出口的帧差 ≤ 1 帧 |
| 压脸 | 静帧里没有字压在眼睛到下巴之间 |
| 安全区 | 所有字在 x 110–970 里（`layout.margin` 110），y 240 以下 |
| 大小 | 小词不小于 50 像素（`layout.min_small`） |
| 强调色 | 每块 ≤ 1 个 |
| 遮挡 | `behind` 里的词确实被头发或身体挡住一部分，没有整个消失 |

## 7. 不要

这些都是做的时候被否掉过的，不要再出现：

- 绕着头转圈的字。
- 底部的大黄字。
- 嘴边散开的声波圈。
- 用思源黑体 Heavy 这类又圆又胖的字做花字；窄体的位置只放窄体。
- 逐字打字（除非对标里明确有），也不要给重点词加回弹或拖影。
- 粗描边、厚阴影、渐变字。
- 胶片颗粒（`grain` 保持 0）。
- 讲流程、讲操作的句子用贴脸字：这种地方应该放真实录屏（见 07 的 R1、R4）。贴脸字只留给态度和情绪。

## 8. 预设外的效果

对标里有现成参数做不出来的字效（比如字母沿弧线飞入后波浪起伏、透镜转场），按方法拆解，再新写：

1. **拆**：按 `02` 第 3 节逐帧测，把效果分成四层：形状（字 / 图形）、运动（路径、速度、缓动）、材质（平面 / 玻璃 / 模糊）、时机（对哪个词、提前几帧）。每层写成数字。
2. **找零件**：
   - 字图：`kinetic.word_img(text, kind, size, color, style)`，返回 `(RGBA 图, (墨迹左, 墨迹右, 中线))`，和预设的字是同一种材质。
   - 亚像素摆放：`core.place(fr, im, cx, cy, s, rot, alpha)`，慢速移动也不会一格一格跳。
   - 时间曲线：`core.sp`、`core.ease`、`core.ease_out5`。
   - 玻璃：看 `03` 第 7 节。
3. **写**：在项目里建 `fx/效果名.py`，写一个函数：

```python
import sys; sys.path.insert(0, "<skill>/scripts")
import core, kinetic, timeline

KS = timeline.preset("kinetic")          # 字体和字的材质从贴脸字幕预设里取，和其他字保持一致

def draw(fr, t, lt, item, style):
    """lt 是从 item["t"] 开始的时间；fr 是 PIL RGB 图，原地画或返回新图。
    style 是这一段的预设（glass 段就是玻璃预设），用到玻璃参数时从这里取。"""
    for i, ch in enumerate(item["text"]):
        p = core.sp(lt - i * 0.04, 3.0, 0.55)
        im, _ = kinetic.word_img(ch, "b", item.get("size", 200), (255, 128, 16), KS)   # 返回 (图, 墨迹范围)
        core.place(fr, im, item["x"] + i * 120, item["y"] + 80 * (1 - p), s=p)
```

4. **挂**：在那一段的时间轴里写 `"overlays": [{"module": "fx/效果名.py", "t": 3.2, "dur": 1.5, "text": "MOTION", "x": 300, "y": 700}]`。
5. **对照**：出 3 张静帧和对标帧并排，用户点头再出动态。
