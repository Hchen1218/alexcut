# 03 液态玻璃

什么时候读：要在口播上放界面元素（输入框、文件、标签、步骤），放素材卡片，或者做章节转场的时候。
代码在 `scripts/glass.py`，手感参数在 `presets/glass.json`。

## 1. 用在哪，不用在哪

| 用 | 不用 |
|---|---|
| 对 AI 做的操作：输入框、发送的文件、AI 回复的标签、进度 | 嘴里说的观点、金句。这些属于「话」，用贴脸字（04） |
| 素材卡片的边框：录屏、成片、截图 | 底部字幕 |
| 章节转场的大字（玻璃字折射身后失焦的画面） | 装饰。没有信息的玻璃块不要放 |

同屏最多一个玻璃元素。章节转场的大字和副标题算一组，讲课版式里的卡片和它的标签胶囊也算一组。

## 2. 材质：为什么看起来像玻璃，不像塑料

实现顺序：先按距离场算出形状，再在边缘一圈做折射，中心不变形。接着轻模糊、提饱和、按背景亮度自适应染色。最后加高光描边和柔和投影。

| 参数（`material`） | 默认 | 作用 | 调大 / 调小会怎样 |
|---|---|---|---|
| `blur` | 2.4 | 玻璃后面的模糊 | 超过 3 像毛玻璃浴室门；低于 1.5 字容易被背景干扰 |
| `amount` | 0.05 | 白色染色 | 超过 0.08 就像一块白塑料片 |
| `adapt` | 1.0 | 按背景亮度自动调染色（亮背景少染，暗背景多染） | 0 = 不自适应，亮背景上会发灰 |
| `bezel` | 16 | 折射带宽度（像素） | 太宽会让整块都变形 |
| `refract` | 22 | 边缘折射强度 | 太大边缘像哈哈镜 |
| `sat` | 1.22 | 玻璃里的饱和度 | 1.0 显得灰 |
| `rim` | 1.0 | 高光描边强度（左上强、右下弱） | 0 就没有玻璃边 |
| `shadow` | 0.22 | 投影 | 太深显得厚重 |

文字用 vibrancy（`vibrancy`）：先测玻璃背后的亮度，超过 `threshold` 150 用深字（22,24,32），否则用白字。不要写死黑字或白字。

## 3. 动效：玻璃怎么长出来

- **生长（`morph`）**：先是一个小圆，起始大小为 `start` 0.56；宽和高用两根不同的弹簧拉开，宽 `spring_w` [1.7, 0.58]，高 `spring_h` [2.6, 0.5]。高先到位，宽后到位，像一滴水被拉长。退场在最后 `out` 0.2 秒内收回。
- **文字（`reveal`）**：玻璃长出来以后逐字浮现，每字间隔 `stagger` 0.022 秒，每个字用 `duration` 0.26 秒上浮 `rise` 10 像素并淡入。
- **卡片（`card`）**：从 `from_scale` 0.9 用弹簧 [2.2, 0.7] 放大到位；圆角 36，玻璃边框 6 像素。边框太厚会让录屏显得小。
- **玻璃字（`glass_text`）**：从 135% 用弹簧 [2.3, 0.55] 落位，折射更强（refract 30、rim 1.4）。
- **章节转场（`chapter`）**：画面用 0.25 秒失焦并压暗 28%，玻璃大字落在 y = 0.42 × 画高，字号 190；大字下方长出副标题胶囊；收尾用 0.3 秒对焦回来。跟口播原速走，不定格。整段至少 1.2 秒，口播太短就往后多盖一两个词。

## 4. 组件和时间轴写法

全部写在 `type: glass` 段的 `items` 里，`t` 是出现时间，`dur` 是持续时长。

```json
{"t0": 9.1, "t1": 15.5, "type": "glass", "base": {"source": "aroll"}, "items": [
  {"kind": "capsule", "t": 10.6, "dur": 3.0, "text": "口播原片.mov · 还没剪", "x": 540, "y": 1050},
  {"kind": "defocus", "t": 12.0, "dur": 3.5, "amount": 1.0},
  {"kind": "card", "t": 12.0, "dur": 3.5, "x": 540, "y": 720, "w": 860, "h": 920,
   "source": "录屏", "src_start": 33.0, "crop": [0.22, 0.05, 0.73, 0.95]},
  {"kind": "glass_text", "t": 14.0, "text": "节奏", "x": 540, "y": 800, "size": 180}
]}
```

- 胶囊文字一行说完，不超过 10 个字。
- 横屏录屏放进卡片：source 写 `"fit": "native", "scale": 2`，再用 `crop` 按比例裁出要看的那一块，例如对话栏。不要整屏塞进去（会有黑边，字也太小）。
- 卡片尺寸：录屏卡宽 860（x 110–970），高 880–960；竖屏成片卡 3:4，750×1000，放在 y 230–1230。
- 卡片和胶囊都不要进字幕带 y 1240–1340；字幕会自动往下让，但让完以后可能出安全区。
- C 版式要压暗多一点（35%）：defocus 的 `amount` 写 1.25（默认压暗 0.28 × 1.25 ≈ 0.35）。

## 5. 检查（先出静帧再渲染）

先跑 `python3 scripts/timeline.py check timeline.json`，安全区、字幕带和同屏数量会自动判。

在玻璃元素出现后 0.5 秒和 1.5 秒各出一张静帧（`compose.py --stills`），每张都看下面几项：

| 检查 | 通过标准 |
|---|---|
| 浅色背景和深色背景各一张 | 两张上玻璃都能看出边，字都清楚 |
| 字色 | 亮背景上是深字，暗背景上是白字 |
| 卡片里的录屏 | 正文字高 ≥ 26 像素（见 07） |
| 位置 | 在 x 110–970、y 240–1500 里，不进字幕带，推镜时不挡嘴 |
| 同屏 | 只有一个玻璃元素（卡片 + 标签算一组） |

## 6. 不要

- 不要用纯色块加粗描边代替玻璃（廉价感的直接来源）。
- 不要把玻璃染成蓝色或其他颜色；强调色只给玻璃里的一个词。
- 不要把模糊开到看不清背后的画面，玻璃的高级感来自「透」。
- 不要让玻璃承载一句观点（材质混用）。
- 不要在同一屏叠两个玻璃元素，比如两个胶囊，或者两张卡片。
- 不要用缩放旋转或闪白做章节转场，只用失焦加玻璃字。

## 7. 预设外的玻璃效果

用户的对标里出现了现有组件没有的玻璃效果（比如两滴玻璃融合、玻璃透镜扩满全屏），按下面的步骤新写：

1. 按 `02` 第 3 节逐帧拆：形状怎么变、多快、折射在哪、文字什么时候出来，全部写成数字。
2. 用现成的零件拼，不要从零写材质：
   - 任意形状：`glass.glass_field(fr, bounds, fn)`，`fn` 返回到边缘的有符号距离。两个形状融合用 `glass.smin`。
   - 圆角矩形距离场：`glass.rrect_sdf`。
   - 文字做成玻璃：`glass.glass_glyphs`。
   - 时间曲线：`core.sp`（弹簧）、`core.ease`、`core.ease_out5`。
3. 写成一个函数 `draw(fr, t, lt, item, style)`，放在项目的 `fx/` 目录，用段落的 `overlays` 挂上（写法见 `04` 第 8 节）。
4. 先出 3 张静帧和对标帧并排对照，用户点头再出动态。
