# 07 可读性与真实性

什么时候读：排分镜时（决定放真实素材还是动画），以及每次出静帧检查时。

观众判断一条教程「可信」，只看三件事：

1. **你说了什么**：真实的对话气泡、真实的指令原文。
2. **它做出了什么**：真实的产出，比如录屏里的回复、样片、成片，而且画面在动。
3. **我看得清**：在手机上字能读出来，不被头像和玻璃挡住。

找素材里的时间点（录屏第几秒说了什么）：`python3 scripts/analyze_ref.py sheet 录屏.mp4 --fps 0.25 --out 素材总览/` 出带时间码的总览图（每 4 秒一张）。这个命令对任何视频都能用，不只是对标。

## 1. 四条规则

| # | 规则 | 怎么检验 |
|---|---|---|
| R1 | 讲操作的句子，画面放真实录屏或真实产出。动画只负责串联和强调，不替代过程 | 每个 C 版式段都能指出素材出处：录屏第几秒，或者哪个文件 |
| R2 | 看得清优先于好看：录屏里的正文字在 1080 宽的画布上字高 ≥ 26 像素；头像、标签不压正文 | 关键帧缩到手机尺寸逐张看（`--sheet`） |
| R3 | 改前改后：同一时刻、两边都在播、差异处框出来 | 并排时两边都在动，至少 1.5 秒 |
| R4 | 贴脸字只留给态度和情绪；讲流程的地方用可视化流程或录屏 | 逐段检查：贴脸字段讲的是观点，不是步骤 |

## 2. 安全区（1080×1920 画布）

抖音、小红书全屏时，左右各裁掉约 97 像素；右下角还有点赞、评论按钮。

| 区域 | 范围 | 参数 |
|---|---|---|
| 内容安全区 | x 110–970 | `kinetic.layout.margin` 110；card 的 `x ± w/2` |
| 上下 | y 240 以上、y 1500 以下不放字 | — |
| 底部字幕 | 得意黑 72 号，中线 y 1290，单行不超过约 12 个字，超过就拆成两条 | `glass.subtitle.size` 72、`y` 0.672、`max_chars` 12 |
| 字幕带 | y 1240–1340 不放卡片、头像、玻璃 | compose 会把字幕挪到玻璃下面，但挪完可能出安全区，所以排版时就要避开 |
| 卡片和字幕之间的标签条 | y 1150–1225 | 卡片外的胶囊、数字放这里 |
| 嘴 | 推镜时卡片不挡嘴（下巴约在 y 840–900，以静帧为准） | — |
| 人物小窗 | 放左下，不放右下 | — |

`compose.py --stills "…" --guides --sheet` 会画红色安全线和黄色字幕带，再拼成一张手机尺寸的总览图。

字幕写法：

- 字幕跟实际录音走；和稿子不一致时以音频为准。
- 品牌名、产品名校正成正确写法；转写听错的专有名词要逐条改。
- 按语义断句，不按字数硬切（`transcribe.py` 已经按标点和停顿切过，仍要人工过一遍）。
- 白字加柔和阴影，不加底框，不做关键词变色。

## 3. 录屏放进卡片

- 横屏录屏不要整屏塞进竖屏：source 写 `"fit": "native", "scale": 2`，用 `crop` 只裁出要看的那一块（例如对话栏）。
- 字高达到 26 像素的算法：录屏原图里正文字高 × (卡片宽 ÷ 裁出来的宽度) ≥ 26。
  - 量原图字高：`python3 scripts/analyze_ref.py sheet 录屏.mp4 --at 秒 --dur 0.1 --grid`，看一行正文占几格。
  - 4K 横屏桌面录屏的正文字高大约是画面宽的 1%，所以裁出来的宽度不能超过画面宽的三分之一左右。
  - 不够时按这个顺序：先裁得更窄，只看说到的那几行，行尾被裁掉可以接受；还不够就请用户把窗口拉窄、字号调大后补录。不要为了看全一行把字缩小。
- 说到哪一句，就放大到那一行，并在那一行上加一层淡淡的高亮。
- 录屏卡宽 860，高 880–960；竖屏成片卡 3:4，750×1000。玻璃边框 6 像素，阴影要轻。

## 4. 改前改后

- 两边都在播同一个时刻，不要用模糊的过渡帧，也不要用定格。
- 并排各宽 420，都在安全区里；或者用一道竖向玻璃从左往右擦过去，再变成并排。
- 差异处用强调色的框选角标框出来。
- 并排至少停 1.5 秒。

## 5. 真实性和隐私

- 屏幕上的数字必须和口播说的一致。改了口播，就同步改画面。
- 录屏里不能露的东西，取景时就避开：账号 ID、链接、客户名称、真实姓名、报价、群名，以及用户指定不能出现的品牌名、分支名、模型名。实在避不开的一两个词，只模糊那个词，不要整块打码。
- 用户说过某个词是敏感词（比如某个品牌名），口播字幕、贴脸字和录屏里都要替换或避开。转写听错的版本也要找出来替换。
- 宁可模糊一块，也不暴露别人的品牌、公司和姓名。
- 只模糊一个词：先在素材上处理好，再放进时间轴。坐标是录屏原图的像素，`between` 是出现的时间段：

```
ffmpeg -i 录屏.mp4 -filter_complex "[0]crop=W:H:X:Y,boxblur=12[b];[0][b]overlay=X:Y:enable='between(t,12,18)'" -c:a copy 录屏_打码.mp4
```

- 时间轴顶层写 `"banned": ["词1", "词2"]`，`timeline.py check` 会在字幕、贴脸字、胶囊、章节里查。录屏画面里的字它查不到，要自己看静帧。

## 6. 画质

- 4K 原片按 1.5 倍解码（source `"scale": 1.5`，即 1620×2880），推镜直接取高清像素，不把 1080 的画面放大。
- 导出 crf 14（`core.encode` 的默认值）。
- 不加胶片颗粒（两个预设的 `grain` 都是 0）。
- 口播原片不镜像翻转，除非用户要求。

## 7. 检查清单（每次出静帧都过一遍）

- [ ] 所有字、卡片、头像都在红线以内
- [ ] 字幕带里只有字幕
- [ ] 录屏正文字高 ≥ 26 像素
- [ ] 头像、标签、玻璃没有压正文，也没有挡嘴
- [ ] 每个 C 版式段都能说出素材出处
- [ ] 画面上的数字和口播一致
- [ ] 没有露出账号、链接、真实姓名、敏感词

## 8. 不要

- 不要用动画演一遍用户其实有录屏的过程。
- 不要为了好看把录屏缩小到看不清。
- 不要把改前改后做成一张静图对比。
- 不要整块打马赛克，只模糊那个词。
- 不要用带烧录字幕的素材段，用没有口播的段，或者把它的字幕带裁掉。
