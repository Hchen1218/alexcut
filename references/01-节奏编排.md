# 01 节奏编排

什么时候读：拿到口播、开始排分镜之前。产出是时间轴 `segments` 的骨架：每段是什么版式，开头和结尾各在哪，哪里密、哪里松。

## 1. 先搞清楚节奏是什么

节奏不是剪得快，而是**信息变化的密度**：观众每隔多久就会看到一个和当前这句话有关的新东西，比如一个字、一次镜头动作、一个界面或一声音效。

| 事实 | 推出来的做法 |
|---|---|
| 刷到视频的人每一秒都在决定要不要划走，前 3 秒最关键 | 开头最密，往后逐渐降 |
| 注意力会被变化抓住，但和内容无关的变化就是噪音 | 每次变化都要挂在口播里的一个词上 |
| 耳朵和眼睛同时收到同一个意思，记得最牢 | 画面只演正在说的这件事，不提前、不拖后 |
| 人脸带来信任，真实界面和真实结果带来可信度 | 讲过程时人不消失；演示尽量用真实录屏 |
| 一直猛会让人麻木 | 猛的段落之后接一段平静的口播；结尾留一段完整的长口播讲情绪 |

## 2. 密度曲线（按片长比例，任何时长都能套）

下面四段的比例来自一条 3:31 的教程定稿版，参照的是一条 106 个镜头的爆款对标和一条 82 个镜头的测评对标。

| 段落 | 占片长 | 贴脸字 | 音效 | 镜头 |
|---|---|---|---|---|
| 钩子 | 0–9% | 每个词都上 | 0.3–0.5 秒一个，大字才配 | 每个关键词都急推或甩镜 |
| 框架（讲接下来要说什么） | 9–24% | 只上关键词 | 1–2 秒一个 | 关键词推一档 |
| 主体（教学 / 讲解） | 24–83% | 每段只在观点句、金句上用 1–2 次 | 4–8 秒一个，只给界面动作、标题、改前改后 | 版式 A 里慢推，C 里不动 |
| 结尾 | 83–100% | 2–3 个关键时刻 | 全段 3–4 个 | 慢推，情绪顶点猛推一次 |

对标的硬数据（拆你自己的对标时，按 `02-对标拆解协议.md` 测出同样几项，用你的数代替这些数）：

| 指标 | 教程对标（竖屏） | 测评对标（横屏 6:16） | 落到时间轴上 |
|---|---|---|---|
| 镜头数 / 中位时长 | 106 个 / 2.2 秒 | 82 个 / 2.55 秒 | 主体段的画面变化间隔中位数控制在 2–3 秒 |
| 每分钟切换 | — | 第 1、2 分钟 18、23 次，最后两分钟 6–8 次 | 前三分之一切换数 ≥ 后三分之一的 2 倍 |
| 人物占比 | 约四分之一 | — | 人物全屏（版式 A）占 25–35% |
| 人物连续出镜 | 中段每次 2–4 秒 | 最长约 23 秒 | 中段每次露脸 ≤ 5 秒，结尾除外 |
| 开场人物时长 | — | 1 秒就切到产品 | 钩子里人物可以只留 1–2 秒，然后给结果画面 |

## 3. 四种版式

全片只用这四种，加新版式之前先问自己：现有四种为什么不够？

| 代号 | 版式 | 用在哪 | 时间轴写法 |
|---|---|---|---|
| A | 口播全屏 + 贴脸字 + 运镜 | 开头、观点句、金句、结尾 | `type: kinetic`；不要字时用 `aroll` 加 `zoom` |
| B | 口播全屏 + 一个玻璃界面元素（输入框、文件胶囊、标签） | 讲「我对 AI 做了什么操作」 | `type: glass`，`base: {source}`，`items` 里放 capsule |
| C | 讲课版式：口播虚化压暗做底，中间是圆角素材卡 | 讲素材、看录屏、看改前改后 | `type: glass`，`items` 里先放 defocus，再放 card |
| T | 章节标题：失焦 + 玻璃大字 | 每个大段开头 | `type: chapter`，`title`、`sub` |

材质分工（R2：一类东西一种材质，不混用）：

- **嘴里说的话**：用平面字，也就是贴脸字（版式 A）。
- **对 AI 做的操作**：输入框、文件、标签、进度这类，用液态玻璃（版式 B）。
- **需要看清的东西**：录屏、对标、成片，放进圆角卡片（版式 C）。

判断一个元素该用哪种：先问它是一句话，还是一个界面，还是一个要看清的证据。

## 4. 转场

- 默认硬切，约占 80%。留人靠的是信息变化，不是转场特效。
- 同一个人的跳剪：两个机位交替，例如 `zoom` 1.0 和 1.15，用来掩盖跳剪。
- 大段落切换用 T（失焦 + 玻璃大字），全片 4–6 次。T 跟口播原速走，不按住画面，也不插空白。
- C 每次停留至少 4 秒，免得来回切得人眼花。C 里换章不必回全屏。

## 5. 同屏上限

- 一屏最多一组贴脸字加一个玻璃元素。讲课版式里，卡片和它的标签胶囊算一组。
- 颜色只用白和一个强调色（默认亮橙 255,128,16）。
- 一个画面只讲一件事：长截图不整屏滚完，只放大说到的那一块（card 的 `crop`）。

## 6. 排分镜的步骤

1. 拿到逐字时间轴（`scripts/transcribe.py`，或用户给的 srt），按句子标出每句是哪一类：钩子、框架、观点、操作、证据、情绪。
2. 按第 2 节的比例算出四段的边界时间，把句子归进去。
3. 按句子类别选版式：观点 / 情绪用 A，操作用 B，证据用 C，换章用 T。
4. 在每段里只挑「能被看见的词」做贴脸字或玻璃，其余句子只留底部字幕。
5. 写进时间轴，跑第 7 节的检查。

## 7. 检查（写完 segments 就跑，不用渲染）

`python3 scripts/timeline.py check timeline.json` 会自动判下表里除「前 3 秒」以外的几项，以及 03、04、07 里的位置和字号规则。

| 检查 | 通过标准 |
|---|---|
| 前 3 秒 | 至少 4 个视觉事件（字、镜头动作、元素） |
| 版式 A 总时长 / 片长 | 25–35%（钩子和结尾的 A 也算） |
| 中段（24–83%）连续版式 A | 单段 ≤ 5 秒 |
| 版式 C 每段时长 | ≥ 4 秒 |
| chapter 个数 | 4–6 个，且每个都在大段开头 |
| 前三分之一的段数和后三分之一的段数 | 前者 ≥ 后者的 2 倍 |
| 同一时刻 | kinetic 段里没有玻璃元素；glass 段里同时可见的卡片 ≤ 1 张、胶囊 ≤ 1 个 |

## 8. 不要

- 不要从头到尾一样密，会让人麻木；也不要开头松、后面紧。
- 不要用跟口播无关的变化去「保持画面在动」，比如装饰粒子、漂浮代码、无意义的转场。
- 不要用缩放旋转、闪白、故障这类转场。
- 不要用动画替代真实过程：讲操作时放真实录屏，动画只负责串联和强调（见 `07-可读性与真实性.md`）。
- 不要一秒内在 A 和 C 之间来回切。
